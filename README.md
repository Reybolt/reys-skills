# reys-skills

A collection of [Claude Code](https://claude.com/claude-code) skills. Each skill
lives in its own folder with a `SKILL.md`.

## Skills

- [making-messages-stick](making-messages-stick/) — Sharpen any title, headline,
  announcement, or doc using the *Made to Stick* (Heath & Heath) SUCCESs
  framework. Names the outcome for the reader instead of the activity, and
  diagnoses drafts against Simple / Unexpected / Concrete / Credible / Emotional
  / Stories.

## Using a skill

Copy a skill folder into your Claude Code skills directory:

```bash
cp -R making-messages-stick ~/.claude/skills/
```

The skill then becomes available via the `Skill` tool in Claude Code.
